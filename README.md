# Yolingo Kids

Official static website concept for Yolingo School, Annaba.

Website: https://yolingo-school.github.io/

This project contains a single self-contained `index.html`, with all styling, interaction scripts and original illustrated artwork embedded in the page. The public school address and phone number come from its public Facebook/Instagram profiles. The Yolingo Kids sub-brand and graphics are a proposed visual concept.

## GitHub Pages

This repository must have GitHub Pages enabled, with **Deploy from a branch**, branch `main`, folder `/(root)`. Once enabled, pushes to `main` publish automatically.
